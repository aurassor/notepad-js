# Um Notepad Básico feito com JavaScript puro
Esse é um projeto que fiz com uso de ia para estudo, todo o projeto foi feito com JavaScript puro, CSS e HTML.

O bloco de notas tem um input para as tarefas e o botão de adicionar,
ao digitar uma tarefa e adicionar, a tarefa fica armazenada na LocalStorage do navegador, impedindo que se percam as tarefas ao recarregar a página. 
    O código sempre começa acessando a LocalStorage e atualizando as tarefas, e frequentemente armazena as tarefas no LocalStorage.
